Проверка графа

    Цвета

    Меняются сразу и запоминаются для этого графа. Цвета нод и акцент общие для обеих тем, фон холста — свой у каждой.

    Языки текстов

    Первый язык — основной: его поля обязательны. Остальные можно заполнять постепенно — в игре непереведённое покажется по-английски. Коды — как столбцы strings.csv: ru, en, de, fr, es, it, pl, pt-br, zh-cn, ja, ko…

    Каталог сцены

    Списки объектов для выбора целей: точки ремонта, двери, пятна, полки, зоны, предметы, враги, заказы. Файл делает Unity: Tools → Weapon Keeper → Story → Export Scene Catalog (scene_catalog.json).

    Открыть граф

    Заменит текущий граф целиком (отменить можно через Ctrl+Z). Файл — story_graph.json из проекта: Assets/01_GAME/08_Story/.

    story_graph.json

    Скачивание здесь недоступно — скопируйте текст и сохраните в Assets/01_GAME/08_Story/story_graph.json. Или просто напишите Claude «синхронизируй граф».
