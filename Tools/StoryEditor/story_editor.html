Проверка графа

    Цвета

    Меняются сразу и запоминаются для этого графа. Цвета нод и акцент общие для обеих тем, фон холста — свой у каждой.

    Языки текстов

    Первый язык — основной: его поля обязательны. Остальные можно заполнять постепенно — в игре непереведённое покажется по-английски. Коды — как столбцы strings.csv: ru, en, de, fr, es, it, pl, pt-br, zh-cn, ja, ko…

    Каталог сцены

    Списки объектов для выбора целей: точки ремонта, двери, пятна, полки, зоны, предметы, враги, заказы. Файл делает Unity: Tools → Weapon Keeper → Story → Export Scene Catalog (scene_catalog.json).

    Открыть граф

    Заменит текущий граф целиком (отменить можно через Ctrl+Z). Файл — story_graph.json из проекта: Assets/01_GAME/08_Story/.

    story_graph.json

    Скачивание здесь недоступно — скопируйте текст и сохраните в Assets/01_GAME/08_Story/story_graph.json. Или просто напишите Claude «синхронизируй граф».

    Папка проекта

    Укажите папку Unity-проекта Weapon Keeper (ту, где лежит Assets). Граф будет храниться прямо в проекте — Assets/01_GAME/08_Story/story_graph.json, — а приложение само сохраняет правки и делает резервные копии.

    Несохранённые правки

    Что бы вы ни выбрали, вторая версия уйдёт в «Историю версий» — её можно будет вернуть.

    Файл изменён снаружи

    story_graph.json поменяли вне редактора (git pull, Unity или другая программа), а у вас есть несохранённые правки. Какую версию оставить?

    Вторая версия не пропадёт — она уйдёт в «Историю версий».

    Файл графа не читается

    Сохранение выключено, чтобы ничего не перезаписать. Восстановите одну из резервных копий ниже или почините файл вручную и перезагрузите окно (Вид → Перезагрузить).

      История версий

      Копии делаются при открытии, раз в 5 минут, пока идут правки, и перед любым восстановлением. Хранятся последние 100 и по одной за день за месяц. Восстановление тоже можно отменить — через Ctrl+Z или эту же историю.
