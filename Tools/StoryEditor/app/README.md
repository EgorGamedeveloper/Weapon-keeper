# Weapon Keeper Story — приложение для Mac

Оболочка (Electron) вокруг редактора сюжета `../story_editor.html`. Граф правится прямо в Unity-проекте:
`Assets/01_GAME/08_Story/story_graph.json`. Как пользоваться — `Docs/Story/STORY_GRAPH.md`, раздел «Приложение для Mac».

## Устройство

| Файл | Что делает |
|---|---|
| `main.js` | Окно, меню, выбор папки проекта, слежение за файлом графа, закрытие только после записи. |
| `preload.js` | Мост `window.storyHost` — всё, что странице можно делать с диском. Node странице недоступен. |
| `storage.js` | Диск: атомарная запись, резервные копии, черновик. Покрыт тестами (`test/`). |
| `scripts/copy-editor.js` | Кладёт копию редактора в `editor/` для сборки. |

Редактор берётся **из проекта** (`Tools/StoryEditor/story_editor.html`): его правки приходят с `git pull`, пересобирать
приложение не нужно. Встроенная копия — запасной вариант, если файла нет или он требует более новый мост.

## Совместимость — правила для изменений

- **Мост.** `HOST_API` в `main.js`, `apiVersion` в `preload.js` и маркер `<!-- story-host-api: N -->` в редакторе.
  Методы моста только добавляются; если редактору нужен новый метод — поднять N в редакторе и `HOST_API` в оболочке
  и выпустить новую сборку. Старая оболочка откроет встроенную копию редактора, а не сломается.
- **Формат графа.** `FILE_VERSION` и `MIGRATIONS` в редакторе: сменили формат — поднять версию и дописать шаг миграции.
  Незнакомые поля сохраняются как есть; файл новее редактора открывается только для просмотра.
- **Данные.** Граф — в проекте (git). Копии и черновик — в `~/Library/Application Support/Weapon Keeper Story/`
  (`backups/<ключ проекта>/`, `drafts/`), удаление приложения их не трогает.

## Разработка

```sh
npm ci
npm test        # тесты storage.js
npm start       # запустить (копирует редактор в editor/)
npm run dist    # собрать .dmg в dist/ (только на Mac)
```

`WK_STORY_USER_DATA=<папка>` — другая папка данных (для автотестов).

Сквозные тесты приложения и редактора — `../tests/run.sh [web|app|all]`. Полное устройство системы сюжета —
`Docs/Story/STORY_EDITOR_ARCHITECTURE.md`.

Сборку для пользователя делает GitHub Actions (`.github/workflows/story-editor-mac.yml`) при правке этой папки:
артефакт `WeaponKeeperStory-mac` и релиз `story-editor-v<версия>`. Перед правкой оболочки поднимите `version` в
`package.json`, иначе новая сборка заменит файл в старом релизе.
