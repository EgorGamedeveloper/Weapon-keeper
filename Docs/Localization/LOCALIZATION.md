# Локализация: таблица переводов

Все тексты игры лежат в одной таблице — `Assets/01_GAME/07_Localization/strings.csv`. В ней есть:
- надписи в сценах;
- тексты, которые собирает код (подсказки у прицела, окно навыков, терминал, HUD, настройки, пауза, достижения);
- названия и описания предметов, квестов, навыков, ящиков и заказов.

Первый столбец — ключ, остальные — языки, по одному столбцу на язык:

| key | ru | en | de | … |
|---|---|---|---|---|
| `hud.action.place` | ЛКМ — поставить | LMB — place | LMT — ablegen | |
| `item.ammobox_556.name` | Коробка патронов 5.56 | Ammo box 5.56 | | |

- **Язык в игре** выбирается в «Настройки → Игра → Язык». В списке все языки, у которых есть столбец, в порядке столбцов.
- **Пустая ячейка** — перевода ещё нет: в игре покажется английский текст. Поэтому новый язык можно переводить постепенно.
- **Строки, ключ которых начинается с `#`,** — это заголовки разделов и комментарии, игра их пропускает.
- **Перевод строки внутри ячейки** — наберите `\n` или переносите прямо в ячейке.
- **`{0}`, `{1}`** — места, куда игра подставляет число или имя (`Уровень {0}` → «Уровень 5»). Их нужно сохранить в переводе, порядок слов при этом можно менять.

## Как открыть и редактировать

- **Google Таблицы** (удобнее всего): Файл → Импорт → Загрузить → `strings.csv`, разделитель — «Автоматически». После правок: Файл → Скачать → CSV, и заменить файл в проекте.
- **LibreOffice Calc**: открыть `strings.csv`, кодировка UTF-8, разделитель — запятая. Сохранять в том же формате.
- **Excel**: Данные → Из текстового/CSV-файла → кодировка «65001: Юникод (UTF-8)», разделитель «Запятая». Сохранять как «CSV UTF-8».
  - Если Excel сохранит через `;` (так бывает при русских региональных настройках), игра это поймёт: разделитель — запятая, `;` или табуляция — определяется автоматически.
  - Двойной щелчок по файлу в Excel с русскими настройками может свалить всё в один столбец. Тогда открывайте через «Данные».

Файл хранится в UTF-8 с BOM, чтобы Excel правильно показывал кириллицу. Инструменты редактора при записи сохраняют этот формат и разделитель.

## Как добавить язык

1. Допишите в первую строку новый столбец с кодом языка: `de`, `fr`, `es`, `it`, `pl`, `pt-br`, `tr`, `uk`, `zh-cn`, `ja`, `ko` и другие. Полный список — `Localization/GameLanguages.cs`, там же можно указать код Steam (`german`). Незнакомый код тоже заработает, но в списке языков он покажется самим кодом.
2. Впишите переводы. Всё, что не переведено, игра покажет по-английски.
3. В Unity запустите **Tools → Weapon Keeper → Localization → Validate**: в окне будет готовность каждого языка в процентах.
4. Запустите **Localization → Check Font**. Для китайского, японского, корейского, тайского и арабского нужен шрифт с этими символами: добавьте его TMP-ассет в Fallback Font Assets шрифта по умолчанию.

Язык игры при первом запуске берётся из Steam, если он есть в таблице. Иначе — язык системы, иначе английский.

## Как попадают в таблицу новые тексты

| Что | Как |
|---|---|
| Надпись, поставленная в сцене руками | **Localization → Extract Texts From Open Scene** — в открытой сцене. Добавит строку (текущий текст — в `ru`) и повесит на надпись компонент `LocalizedText` |
| Новый предмет, квест, навык, ящик, заказ | **Localization → Export Data Texts** — допишет его название и описание в раздел «Данные: …». Ключ строится из id ассета (`item.<itemId>.name`), поэтому id после выхода игры не меняют. Если русский текст в ассете и в таблице разошёлся, пункт спросит, какой считать правильным |
| Строка в коде | В коде `Loc.Get("раздел.ключ")` или `Loc.Get("раздел.ключ", число)`, строку — в таблицу вручную |

Пока текста данных нет в таблице, игра показывает русский текст из самого ассета. Поэтому новый предмет не сломает интерфейс, он просто будет без перевода, пока не запустите Export Data Texts.

## Проверка перед релизом

- **Localization → Validate**:
  - пустые `ru`/`en`;
  - повторы ключей;
  - ключи из кода и сцен, которых нет в таблице;
  - невыгруженные тексты данных;
  - готовность каждого языка.
- **Localization → Check Font** — всем ли символам таблицы хватает шрифта.
- В игре переключите язык в настройках: подсказки у прицела, квесты, инвентарь и панель уровня сменятся сразу, окна — при следующем открытии.
